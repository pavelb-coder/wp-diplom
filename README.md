# WP Diplom — генератор сертификатов и дипломов

Плагин WordPress для автоматической генерации сертификатов, грамот и дипломов в PDF: визуальные бланки с полями в миллиметрах, подстановка данных через плейсхолдеры, отправка на e-mail и публичная проверка подлинности по коду.

- **Версия:** 1.4.0
- **Требования:** WordPress 6.0+, PHP 7.4+
- **Зависимости:** нет. PDF-движок собственный — Composer, mPDF, TCPDF и GD не нужны
- **Лицензия:** GPL v2 или новее
- **Репозиторий:** https://github.com/pavelb-coder/wp-diplom

---

## Возможности

| Возможность | Детали |
|---|---|
| **Бланки** | Отдельный тип записи: формат страницы (A4/A5/Letter, альбомная и книжная), фоновое изображение, цвет подложки, рамка, произвольный набор полей |
| **Поля** | Позиция и размер в миллиметрах, кегль в pt, гарнитура (sans/serif), начертание, цвет, выравнивание, верхний регистр, автоматический перенос по словам |
| **Тексты** | Стандартные фразы правятся в настройках (для всех бланков) или в самом бланке (переопределение); свои блоки текста с любым содержанием и оформлением |
| **Плейсхолдеры** | `{recipient_name}`, `{course_title}`, `{course_hours}`, `{teacher}`, `{date}`, `{number}`, `{organization}`, `{code}`, `{custom_КЛЮЧ}` |
| **E-mail** | Письмо с вложением PDF, настраиваемые тема и текст с плейсхолдерами |
| **Проверка подлинности** | Код из 12 символов, публичная страница `[wpdc_verify]`, отдача PDF по `/certificate/{код}/`, отзыв сертификата |
| **Нумерация** | `WPD-2026-0001`, префикс и разрядность настраиваются, счётчик сбрасывается ежегодно |
| **Кэширование** | PDF собирается один раз и пересобирается при изменении данных сертификата |
| **Безопасность** | Nonce и проверки прав во всех обработчиках, экранирование вывода, `abspath`-guard, каталог PDF закрыт от листинга |

## Установка

1. Скопируйте каталог в `wp-content/plugins/wp-diplom` либо загрузите ZIP через **Плагины → Добавить новый → Загрузить плагин**.
2. Активируйте плагин. При активации создаётся бланк «Сертификат (по умолчанию)».
3. Откройте **Сертификаты → Настройки** — укажите организацию, нумерацию и параметры письма.

## PDF-шаблоны

Вместо рисования бланка с нуля можно загрузить готовый сертификат в PDF: макет
делается в любом редакторе, а плагин печатает данные получателя поверх него.

- файл переносится как **форма (Form XObject)** — векторная графика и текст остаются векторными, растеризации нет;
- размер страницы берётся из PDF автоматически, координаты полей — в миллиметрах от верхнего левого угла;
- поддерживаются многостраничные PDF (выбор страницы), поворот `/Rotate`, изображения и шрифты внутри шаблона;
- файлы с паролем и битые PDF отклоняются с понятным сообщением.

Читается классический xref, xref-потоки PDF 1.5+, сжатые объектные потоки
`/ObjStm` и `FlateDecode` с предикторами PNG — то есть файлы из Word, Canva,
Illustrator, Figma и типографий.

## Создание сертификатов из кода

В интерфейсе нет формы «добавить сертификат» и нет массовой генерации: сертификаты выдаются программно, когда на сайте происходит событие — окончился курс, прошла оплата, закрылся вебинар.

```php
$id = WPDC_Certificate::create(
	array(
		'recipient'   => 'Иванов Иван Иванович',
		'email'       => 'ivan@example.com', // необязательно
		'course'      => 'Веб-разработка на WordPress',
		'hours'       => 72,
		'teacher'     => 'Петров П. П.',
		'template_id' => 12,                  // необязательно, иначе бланк по умолчанию
		'custom'      => array( 'group' => 'ВР-21' ), // → {custom_group}
	)
);

if ( is_wp_error( $id ) ) {
	// Ошибка: нет получателя, бланк не найден и т. п.
}

WPDC_Certificate::pdf( $id );        // путь к PDF (собирается один раз и кэшируется)
WPDC_Email::send( $id );             // письмо с вложением
```

Номер (`WPD-2026-0001`) и код проверки (12 символов) присваиваются в момент создания. Дополнительные поля из `custom` доступны в текстах как `{custom_КЛЮЧ}`.

Готовые точки подключения — на усмотрение сайта: `user_register`, `woocommerce_order_status_completed`, окончание курса в LMS, форма на сайте. Плагин не навязывает ни одну из них.

## Тексты сертификата

Фразы, которые подставляются автоматически, живут отдельно от положения полей — их можно править, не трогая вёрстку.

**Где править**

| Уровень | Где | Область действия |
|---|---|---|
| Общие настройки | **Сертификаты → Настройки → Тексты сертификата** | все бланки, предпросмотр, любая выдача из кода |
| Бланк | Редактор бланка → блок **«Тексты бланка»** | только этот бланк |
| Поле бланка | Блок «Поля бланка» | запасной текст, если ничего не задано выше |

Старшинство: **бланк → настройки → текст поля → встроенное значение**. Пустое поле в бланке означает «как в настройках», поэтому переопределять нужно только то, что действительно отличается.

**Слоты:** организация, заголовок, подзаголовок, фраза об обучении, дата, номер, подпись, строка проверки подлинности. Для каждого есть список готовых формулировок.

**Свои блоки.** В блоке «Поля бланка» кнопка «+ Добавить свой блок» добавляет произвольный прямоугольник: любой текст или плейсхолдер, свои координаты, кегль, цвет, выравнивание и регистр. Свой блок не привязан к стандартным фразам и не перезаписывается настройками.

**Плейсхолдеры** работают в любом тексте на любом уровне: `{recipient_name}`, `{course_title}`, `{course_hours}`, `{date}`, `{number}`, `{teacher}`, `{organization}`, `{code}`, `{verify_url}`, `{site_name}`.

## Совместимость с другими плагинами

Плагин использует собственное пространство имён **`WPDC` / `wpdc`** во всём: классы, константы, функции, опции, мета-ключи, типы записей, хуки, CSS-классы, хэндлы, каталог PDF.

Это сделано после реального конфликта с плагином [WP Olympiad Design](https://github.com/pavelb-coder/wp-design) (v2.14.0), который занимает префикс `WPD`/`wpd`. Совпадали:

| Что | Конфликт |
|---|---|
| `WPD_DIR`, `WPD_URL`, `WPD_VERSION` | WP Olympiad Design объявляет их без `defined()`, поэтому второй плагин получал чужой путь и падал на `require_once` |
| класс `WPD_Renderer` | `Cannot declare class WPD_Renderer, because the name is already in use` |
| опция `wpd_settings` | общие настройки у двух разных плагинов |
| мета `_wpd_page` | разные смыслы на одних и тех же записях |

Проверка автоматизирована: `php tests/conflict-test.php` падает, если в коде появится любое имя из пространства `WPD`/`wpd`.

Слаг плагина (`wp-diplom`), текстовый домен и имена файлов архивa не менялись — обновление ставится поверх.

## Быстрый старт

1. **Сертификаты → Бланки → Добавить бланк.** Выберите формат, при необходимости загрузите фон и настройте рамку.
2. В блоке «Поля бланка» задайте текст и координаты. Кнопка **«Открыть предпросмотр PDF»** покажет результат с демонстрационными данными.
3. **Сертификат создаётся из кода** — вызовом `WPDC_Certificate::create()` по событию на сайте. Номер, код проверки и PDF формируются автоматически (см. раздел ниже).
4. В списке **Сертификаты** у записи есть действия **«Скачать PDF»** и **«Отправить на e-mail»**.

## Как устроен PDF

Внешние библиотеки не используются — иначе плагин нельзя было бы поставить без Composer, а mPDF/TCPDF добавляют 30–60 МБ.

- **`WPDC_PDF_Font`** читает таблицы TrueType (`head`, `hhea`, `maxp`, `hmtx`, `cmap`, `glyf`, `loca`), находит глиф по Unicode-коду и считает ширину строки. Шрифт встраивается целиком как `CIDFontType2` с кодировкой `Identity-H`, текст пишется двухбайтовыми глифами, а карта `ToUnicode` возвращает корректное копирование и поиск по PDF.
- **`WPDC_PDF_Writer`** собирает документ: страницы, векторные прямоугольники и линии, текст с переносом и выравниванием, изображения. JPEG встраивается как есть (`DCTDecode`), PNG декодируется собственным декодером (`FlateDecode`), прозрачность уходит в `/SMask`. Зависимости от расширения GD нет.
- **`WPDC_Renderer`** переводит конфигурацию бланка и данные сертификата в вызовы writer'а. Класс не обращается к WordPress, поэтому тестируется автономно.

Кириллица работает из коробки, потому что шрифты DejaVu содержат её полностью.

## Версионирование

Версия — строго в формате **`x.y.z`** (SemVer). Единственный источник истины — заголовок `Version:` в `wp-diplom.php`; функция `wpdc_version()` читает его через `get_file_data()`, поэтому дублировать номер в коде не нужно.

| Часть | Когда повышать |
|---|---|
| `MAJOR` | несовместимые изменения: переименование хуков, опций, мета-ключей |
| `MINOR` | новая функциональность: новый формат, тип поля, шорткод |
| `PATCH` | исправления, тексты, стили |

```bash
./bin/bump-version.sh 1.1.0          # обновит заголовок, README и CHANGELOG
./bin/bump-version.sh 1.1.0 --dry-run
./bin/check-version.sh
```

## Ограничения и заметки

- Шрифт встраивается целиком, поэтому каждый PDF весит около 1 МБ. Для тысяч документов имеет смысл включить сабсеттинг — это следующий шаг развития.
- PNG поддерживается 8-битный без интерлейса (типы 0/2/3/4/6). Прочие форматы конвертируются через GD, если расширение установлено.
- Массовая отправка идёт через `wp_mail()`: на общем хостинге ставьте SMTP-плагин и учитывайте суточные лимиты.
- PDF-файлы лежат в `wp-content/uploads/wpdc-certificates/` и пересобираются при изменении записи.
