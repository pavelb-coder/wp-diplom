Автоматическая генерация сертификатов, грамот и дипломов в PDF: визуальные бланки, программная выдача по событию на сайте, отправка на e-mail и проверка подлинности по коду.

== Description ==

= Совместимость =

Плагин использует собственное пространство имён WPDC/wpdc (классы, константы, опции, мета-ключи, типы записей). Конфликтов с плагином WP Olympiad Design (pavelb-coder/wp-design), который занимает префикс WPD/wpd, нет.


Плагин создаёт PDF-сертификаты по настраиваемым бланкам. Внешние библиотеки не требуются: PDF-движок написан на чистом PHP и поддерживает кириллицу через встроенные шрифты DejaVu.

**Бланки**

* Форматы A4, A5, Letter — альбомная и книжная ориентация.
* Фоновое изображение (JPEG или PNG с прозрачностью), цвет подложки, рамка.
* Любое количество текстовых полей: позиция и размер в миллиметрах, кегль в pt, гарнитура, начертание, цвет, выравнивание, верхний регистр.
* Свои шрифты: блок «Шрифты бланка» подключает любые .ttf из медиатеки (обычное и жирное начертание), они появляются в списке гарнитур у полей.
* Предпросмотр PDF с демонстрационными данными прямо из редактора бланка.

**Свои шрифты**

* В редакторе бланка — метабокс «Шрифты бланка»: файл .ttf выбирается из медиатеки, тип font/ttf разрешён.
* У шрифта есть название для списка и необязательный файл жирного начертания.
* Подключённые гарнитуры появляются в списке «Гарнитура» у каждого поля рядом со встроенными Sans и Serif.
* Ошибки шрифта не ломают генерацию: поле с неизвестной гарнитурой печатается встроенным Sans.

**Тексты**

* Все стандартные фразы бланка (организация, заголовок, подзаголовок, фраза об обучении, дата, номер, подпись, строка проверки) правятся в редакторе бланка — в блоке «Тексты бланка».
* Пустое поле означает «как по умолчанию»: действует текст поля бланка, а если его нет — встроенная фраза.
* Готовые варианты формулировок подставляются в один клик.
* Свои блоки текста: произвольное содержание или плейсхолдер со своим положением, кеглем и цветом.
* Название курса/программы можно задать в бланке — оно подставится вместо {course_title}, если в карточке сертификата курс не заполнен.
* Старшинство: бланк → текст поля → встроенное значение.

**Плейсхолдеры**

`{recipient_name}`, `{recipient_email}`, `{course_title}`, `{course_hours}`, `{date}`, `{number}`, `{organization}`, `{site_name}`, а также `{custom_КЛЮЧ}` для произвольных полей сертификата.

**Параметры бланка**

Все настройки живут в бланке: организация, префикс и разрядность номеров, проверка подлинности, страница с шорткодом проверки и отметка «бланк по умолчанию». Отдельной страницы настроек нет.

**Выдача сертификатов**

Сертификат создаётся из кода по событию на сайте: `WPDC_Certificate::create( array( 'recipient' => 'Иванов Иван', 'course' => 'Название программы', 'hours' => 72 ) )`. Номер и код проверки присваиваются автоматически, PDF собирается при первом обращении и кэшируется. В списке сертификатов доступны скачивание и отправка письмом.

**Проверка подлинности**

Каждый сертификат получает код из 12 символов. Шорткод `[wpdc_verify]` выводит форму проверки, а `/certificate/{код}/` отдаёт PDF. Сертификат можно отозвать — тогда проверка вернёт соответствующий статус.

**Шорткоды**

* `[wpdc_verify]` — форма проверки по коду.
* `[wpdc_certificate id="123"]` — карточка сертификата.
* `[wpdc_certificate code="a1b2c3d4e5f6"]` — карточка по коду.

== Installation ==

1. Загрузите каталог `wp-diplom` в `/wp-content/plugins/` или установите ZIP через «Плагины → Добавить новый».
2. Активируйте плагин.
3. Создайте бланк в разделе «Сертификаты → Бланки».
4. Заполните «Параметры бланка» — организация, нумерация, проверка подлинности.

== Frequently Asked Questions ==

= Нужен ли Composer или mPDF? =

Нет. PDF собирается встроенным движком, зависимостей нет.

= Будет ли работать кириллица? =

Да. В комплект входят шрифты DejaVu Sans и DejaVu Serif (свободная лицензия), они встраиваются в PDF вместе с картой ToUnicode — текст копируется и ищется.

= Почему PDF весит около 1 МБ? =

Шрифт встраивается целиком, без сабсеттинга. Это плата за отсутствие зависимостей и предсказуемый результат; при большом объёме документов имеет смысл добавить сабсеттинг.

= Где хранятся файлы? =

В `wp-content/uploads/wpdc-certificates/`. Каталог закрыт от листинга, файлы пересобираются при изменении сертификата.

= Можно ли удалить все данные при удалении плагина? =

Да, добавьте в `wp-config.php` строку `define( 'WPDC_REMOVE_ALL_DATA', true );` — тогда будут удалены записи, метаданные и PDF.
