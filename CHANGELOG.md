# Changelog

Все заметные изменения плагина **WP Diplom**.
Формат версий — `x.y.z` ([SemVer](https://semver.org/lang/ru/)): `MAJOR.MINOR.PATCH`.

## История изменений

### 1.2.0 — 2026-11-06

**Добавлено**
- **PDF-шаблон бланка.** Готовый сертификат можно загрузить файлом `.pdf` — данные получателя печатаются поверх него. Страница переносится как форма (Form XObject): векторная графика и текст остаются векторными, растеризации нет, качество не теряется.
- Новый класс `WPDC_PDF_Source`: собственный разбор PDF без внешних библиотек. Поддерживает классический xref и xref-потоки (PDF 1.5+), объектные потоки `/ObjStm`, фильтр `FlateDecode` с предикторами PNG, наследование `/Resources` и `/MediaBox`, `/Rotate`, многостраничные файлы.
- Формат страницы «По размеру PDF-шаблона»: после загрузки файла бланк автоматически печатается в его размере, координаты полей задаются в миллиметрах от того же угла.
- Выбор PDF из медиатеки или загрузка напрямую; удаление шаблона; выбор номера страницы для многостраничных файлов.
- Понятные ошибки вместо «белого экрана»: не-PDF, битый файл и PDF с паролем отклоняются с объяснением.

**Изменено**
- Раздел «Программы» (таксономия `wpdc_program`) удалён.
- Пункт «Новый сертификат» (`Добавить сертификат`) убран: сертификаты создаются только массовой генерацией и API, чтобы не появлялись записи без номера и кода проверки.

**Исправлено**
- Текст PDF-шаблона больше не закрашивается цветом фона: форма наследует графическое состояние страницы, поэтому перед её выводом цвет сбрасывается на чёрный.

### 1.1.0 — 2026-11-06

**Исправлено**
- Конфликт с плагином **WP Olympiad Design** (`pavelb-coder/wp-design`), из-за которого активация падала с фатальной ошибкой. Оба плагина использовали префикс `WPD`: совпадали константы `WPD_DIR`/`WPD_URL`/`WPD_VERSION`, класс `WPD_Renderer`, опция `wpd_settings` и мета `_wpd_page`. WP Olympiad Design объявляет константы без проверки, поэтому второй плагин получал чужой `WPD_DIR` и падал на `require_once` несуществующего файла.
- Все глобальные имена переведены в собственное пространство **`WPDC` / `wpdc`**: классы, константы, функции, опции, мета-ключи, типы записей (`wpdc_template`, `wpdc_certificate`, `wpdc_program`), хуки, CSS-классы, хэндлы скриптов, слаг каталога PDF (`uploads/wpdc-certificates`). Имена файлов тоже обновлены (`class-wpdc-*.php`).
- Константы объявляются через `defined()`; вторая копия плагина больше не приводит к «Cannot declare class».

**Добавлено**
- Тест `tests/conflict-test.php`: падает, если в коде появится любое имя из пространства `WPD`/`wpd`.

### 1.0.1 — 2026-11-06

**Исправлено**
- Активация больше не может привести к фатальной ошибке: код активации обёрнут в `try/catch ( Throwable )`. При сбое плагин включается, а точный текст ошибки (файл, строка, версия PHP) показывается в админке.
- Загрузка плагина (`wpdc_bootstrap`) защищена так же — внутренняя ошибка не превращается в белый экран.

**Добавлено**
- Диагностический файл `wpdc-diagnostics.php` (не входит в архив плагина): проверка окружения, целостности файлов, синтаксиса всех PHP-файлов и загрузки классов. Проверка синтаксиса выполняется до загрузки WordPress, поэтому отчёт формируется даже при неработоспособном плагине.

### 1.0.0 — 2026-11-06

Первый релиз.

**Генерация документов**
- Собственный PDF-движок без внешних зависимостей: `WPDC_PDF_Writer` (страницы, фигуры, текст, изображения) и `WPDC_PDF_Font` (парсер TrueType, `CIDFontType2`, `Identity-H`, `ToUnicode`).
- Полная поддержка кириллицы через встроенные DejaVu Sans/Serif и Sans-Bold.
- Встраивание JPEG без перекодирования (`DCTDecode`) и PNG собственным декодером (`FlateDecode`) с сохранением прозрачности в `/SMask`. Расширение GD не требуется.
- Рендерер `WPDC_Renderer` не зависит от WordPress — тестируется автономно.

**Бланки**
- Тип записи `wpdc_template`: формат A4/A5/Letter в двух ориентациях, фон (cover/contain/stretch), цвет подложки, рамка.
- Поля с координатами в миллиметрах, кеглем в pt, гарнитурой sans/serif, начертанием, цветом, выравниванием, верхним регистром и переносом по словам.
- Предпросмотр PDF с демонстрационными данными из редактора бланка.

**Сертификаты**
- Тип записи `wpdc_certificate` с полями получателя, программы, часов, преподавателя, даты и произвольных метаданных.
- Автоматическая нумерация `WPD-2026-0001` с настраиваемым префиксом и разрядностью, сброс счётчика ежегодно.
- Код проверки из 12 символов, кэширование PDF, пересборка при изменении данных, удаление файла при удалении записи.

**Массовая работа**
- Импорт CSV: разделитель `;` или `,`, автоопределение, русские и английские заголовки, произвольные колонки в `custom_*`.
- Необязательная отправка писем сразу после генерации, ZIP со всеми PDF.

**Публичная часть**
- Шорткоды `[wpdc_verify]` и `[wpdc_certificate]`.
- Отдача PDF по адресу `/certificate/{код}/`, статусы «действителен», «не найден», «отозван».
- Стили фронтенда с адаптивом.

**Прочее**
- Письма с вложением PDF, настраиваемые тема, текст и отправитель.
- Тесты: PDF-движок, рендерер, интеграционные с заглушками WordPress.
- Версия `x.y.z` из заголовка плагина через `get_file_data()`, скрипты `bin/bump-version.sh` и `bin/check-version.sh`.
- Удаление данных при деинсталляции (полное — по флагу `WPDC_REMOVE_ALL_DATA`).
